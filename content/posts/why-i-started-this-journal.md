This journal exists because the best way I know to learn something is to explain it.

## The plan

Short notes, each about one idea. Code that runs. No hot takes.

## What to expect

- The fundamentals of Server and Client Components.
- Patterns for data fetching, streaming and caching.
- Later, experiments with AI-assisted writing tools built on the same stack.

If a note helps you, that is a bonus. If it is wrong, I would love to hear about it.
